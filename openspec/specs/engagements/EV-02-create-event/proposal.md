# Proposal EV-02: Créer un événement

## Summary
Formulaire de création d'un événement avec sélection multi des participants dès la création.

## Motivation
Les événements doivent être créés rapidement avec leurs participants pour permettre le calcul du taux d'engagement.

## Proposed Solution
Formulaire avec champs obligatoires (nom, date, type) et optionnels (description), plus interface de sélection multi-astronautes avec barre de recherche et photos.

## Scope
### In scope
- Champs : nom (required), date (required), type (required), description (opt)
- Sélection multi de participants lors de la création
- Interface : barre de recherche + liste avec photos

### Out of scope
- Récurrence d'événements
- Notification aux participants
- Génération de points (les événements ne génèrent pas de points)
